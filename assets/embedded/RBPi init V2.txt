*************DESCARGAS de paquetes***********************

Herramientas para compilar:
	sudo apt install cmake build-essential pkg-config git

Librerías para imagen y video:
	sudo apt install libjpeg-dev libtiff-dev libjasper-dev libpng-dev libwebp-dev libopenexr-dev --fix-missing --fix-broken
	sudo apt install libavcodec-dev libavformat-dev libswscale-dev libv4l-dev v4l-utils libxvidcore-dev libx264-dev libdc1394-22-dev libgstreamer-plugins-base1.0-dev libgstreamer1.0-dev ffmpeg fswebcam gpicview

Librerías backend para GUI (interfaz)
	sudo apt-get install libgtk-3-dev
	(Podría ser además libqtgui4 libqtwebkit4 libqt4-test python3-pyqt5)

(posiblemente otra para evitar warnings sudo apt-get install libcanberra-gtk*)

Librerías de optimizaciones numéricas para que OpenCV corra a una velocidad decente:
	sudo apt install libatlas-base-dev liblapacke-dev gfortran

Para formatos de datos jerárquicos (HDF5):
	sudo apt install libhdf5-dev libhdf5-103

Python:
	sudo apt install python3-dev python3-pip python3-numpy

Clonar OpenCV (cambiar el directorio a /home (si lo permite))(tarda una hora o descargar directo versión 4.7):
	git clone https://github.com/opencv/opencv.git
	git clone https://github.com/opencv/opencv_contrib.git


*************CONFIGURACIÓN***********************
Cambiando el tamaño de paginación:
Entrar:
	sudo nano /etc/dphys-swapfile
Cambiar:
	CONF_SWAPSIZE=100 por CONF_SWAPSIZE=2048
Salvar.

Reiniciar el servicio sin reiniciar la rasp:
	sudo systemctl restart dphys-swapfile


*************COMPILAR**************************
Crear directorio para compilación:
	mkdir /opencv/build
	cd /opencv/build

Generar CMAKE (tarda un 10 min aprox):
cmake -D CMAKE_BUILD_TYPE=RELEASE \
-D CMAKE_INSTALL_PREFIX=/usr/local \
-D INSTALL_C_EXAMPLES=ON \
-D INSTALL_PYTHON_EXAMPLES=OFF \
-D OPENCV_ENABLE_NONFREE=ON \
-D BUILD_TESTS=OFF \
-D ENABLE_NEON=ON \		#Revisar la arquitectura arm de la tarjeta v8 o v7
-D ENABLE_VFPV4=ON \		#mismo caso
-D WITH_CUDA=OFF \
-D WITH_CUFFT=OFF \
-D WITH_CUBLAS=OFF \
-D WITH_NVCUVID=OFF \
-D WITH_OPENCL=OFF \
-D WITH_OPENCLAMDFFT=OFF \
-D WITH_OPENCLAMDBLAS=OFF \
-D BUILD_opencv_apps=OFF \
-D BUILD_DOCS=OFF \
-D BUILD_PERF_TESTS=OFF \
-D BUILD_EXAMPLES=OFF ..


Otra opción:
	cmake -D CMAKE_BUILD_TYPE=RELEASE \
    	-D CMAKE_INSTALL_PREFIX=/usr/local \
    	-D OPENCV_EXTRA_MODULES_PATH=~/opencv_contrib/modules \
    	-D ENABLE_NEON=ON \
    	-D ENABLE_VFPV3=ON \
    	-D BUILD_TESTS=OFF \
    	-D INSTALL_PYTHON_EXAMPLES=OFF \
    	-D OPENCV_ENABLE_NONFREE=ON \
    	-D CMAKE_SHARED_LINKER_FLAGS=-latomic \
    	-D BUILD_EXAMPLES=OFF ..

Compilar, no cambiar de directorio (tarda como 18 horas):
	make

Instalar:
	sudo make install
	sudo ldconfig

Regresar el sawp a valor original:
	sudo nano /etc/dphys-swapfile
	CONF_SWAPSIZE=100
	sudo systemctl restart dphys-swapfile
