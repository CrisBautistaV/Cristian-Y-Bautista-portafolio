******************Montar SD********************
	Apagar (con botón POWER) y desconectar la BBB o sudo shutdown now
	Insertar SD en BBB y conectar BBB al PC, accesar BBB a través de SSH
	Listar contenido del directorio “media”
	ls -al /media
	Si en la terminal no se muestra la lista de directorio, entonces se debe crear la carpeta media y la carpeta card o 	la que 	falte. Crear la carpeta card:
	mkdir /media/card
	Montar la SD: mount -v /dev/mmcblk0p1 /media/card
	Mostrar el contenido de la SD	ls -al /media/card
	
	NOTAS:
	-Si se inserta la SD antes de energizar la BBB, el sistema asigna mmcblk0p1 al SD
	-Si se inserta la SD cuando la BBB esta energizada, el sistema asigna mmcblk1p1 al SD

	Automatizar el montado de la SD para no repetir lo anterior cada vez que se
	enciende la BBB. Abrir fstab en el editor “nano”:
	nano /etc/fstab
	Adicionar: /dev/mmcblk0p1 /media/card auto auto,rw,async,user,nofail 0 0

*************CONFIGURACIÓN***********************

Para compilar necesita una paginación más grande (swap) 
que se debe de crear en la SD una vez montada (funciona)
	sudo mkdir -p /media/card/swap/
	sudo dd if=/dev/zero of=/media/card/swap/swap0 bs=64M count=64
	sudo chmod 0600 /media/card/swap/swap0
	sudo mkswap /media/card/swap/swap0
	sudo swapon /media/card/swap/swap0
	sudo swapon -s (permite ver las swap encendidas)
